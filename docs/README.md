# Project documentation

This folder contains the project definitions, quality review, and responsible-AI documentation for the exposed-rebar inspection prototype.

## Documents

- [Class definition](class_definition.md): Defines the `exposedrebar` target class, inclusion/exclusion rules, and annotation requirements.
- [Error analysis](error_analysis.md): Records observed and potential false positives, false negatives, engineering consequences, and mitigations.
- [Governance checklist](governance_checklist.md): Describes intended use, dataset rights, privacy and PII precautions, human oversight, and safe-use limits.

## Responsible use

The model is an image-screening aid. Its outputs must be reviewed by a qualified structural engineer and must not be used alone to determine corrosion severity, structural capacity, repair scope, or repair quantities.docs/error_analysis.md
