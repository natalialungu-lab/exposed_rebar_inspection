# Data

## Dataset availability

The original training images and labels are not redistributed in this repository.

The exposed-rebar dataset used for this prototype was obtained from Roboflow Universe. The root README provides the dataset author, source URL, and Creative Commons Attribution 4.0 International (CC BY 4.0) licence information.

## Repository contents

This repository contains only derived project artefacts, including:

- trained model weights;
- training and validation metrics;
- training curves;
- selected inference and validation prediction images;
- documentation describing the dataset class, governance controls, and error analysis.

## Data rights and privacy

Before adding new inspection photographs, users must confirm that they have permission to use the images and that the images do not expose confidential client information, sensitive asset locations, identifiable people, faces, vehicle registration plates, or other personal data.

Real site images must not be uploaded to a public repository unless their use and publication have been authorised.
